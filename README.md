# Shopblok Starter

A brand-neutral storefront starter: **Medusa v2** (commerce) + **Next.js 16** with embedded **Payload CMS 3** (content), built on an atomic design system (shadcn/ui + Tailwind v4).

**Status:** M0 (the foundation) is **done**: the Windows exit check (W2) passed on its second run, 2026-10-13 ([SETUP.md](docs/SETUP.md#windows-exit-check-w2-second-run)), so the exit criteria (plan §7) hold on Linux and on Windows. T00, T01, W1, W2 and the W2 fixes ran on Windows; C0 and the rest of M0 ran in a Claude Code cloud environment. **M1 (design foundations) is done**: the Windows check and design review (W3) passed on 2026-10-17 ([SETUP.md](docs/SETUP.md#windows-check-and-design-review-w3)). The Figma kit's variables are exported and `pnpm tokens` builds the tokens from them, the 32 atoms of SPEC §9.3 are in `packages/ui`, the design-system page shows them, CI checks every atom at three widths in two locales, and ADR 0004 settles where the catalog pages' data lives ([plan](docs/plans/M1.md); SETUP.md has a section for each task). **M2 (molecules, organisms and the registry) is in progress** ([plan](docs/plans/M2.md)): T27 (CI for M2), T28 (root files answer 404), T29 (the registry), T30 (view models, copy and fixtures), T31 (primitives and providers) and T32 (product molecules) are done.

**Quickstart** (no keys, no accounts; prerequisites and the details are in [docs/SETUP.md](docs/SETUP.md#quickstart-no-keys-no-accounts): Node 22.22+, pnpm 12.10.1 installed with `npm install -g pnpm@12.10.1`, Corepack off, Docker running):

```bash
pnpm install --frozen-lockfile
docker compose up -d --wait   # Postgres, Redis, Meilisearch, Mailpit
pnpm bootstrap                # .env files, migrations, seeds, admins, keys: about a minute
pnpm dev                      # Medusa on :9000, the storefront and Payload on :8000
```

Then http://localhost:8000 (Cyprus, Greek, EUR), `/us`, `/ch/fr`, the Payload admin at `/admin` and the Medusa admin at http://localhost:9000/app, both with `admin@example.com` and the `DEV_ADMIN_PASSWORD` in `apps/backend/.env`. Check the setup with `pnpm run doctor` (never `pnpm doctor`, which is pnpm's own command).

**The design-system page** is at http://localhost:8000/design-system/en in `pnpm dev` (also `/de`, `/fr` and `/el`): Foundations (colours, type, spacing, radius, shadows, motion, icons and credits) and every atom, at 375, 768 and 1440 px. A production build serves it only if it was built with `DESIGN_SYSTEM_ENABLED=true`; otherwise every `/design-system/…` URL is a 404. `pnpm tokens` rebuilds the CSS tokens after a change to `packages/ui/tokens/`, and [docs/SETUP.md](docs/SETUP.md#the-design-system-page-tokens-and-the-figma-export-m1) says how to run the checks and how to export from Figma again.
