# Next session: run T13 (`pnpm bootstrap`), in the cloud

The M0 plan runs in a Claude Code cloud environment (decision D16 in [plans/M0.md](plans/M0.md)). T12, the Medusa data layer and the wiring page, is done: `apps/storefront/src/lib/{env, cache}.ts`, `lib/medusa/{sdk, regions, products}.ts` and `lib/cms/site.ts` are the data layer, and the market home (`[market]/page.tsx`) shows the market, its language, the Medusa region and currency, the store's price-filter currencies, Payload's published pages and 4 products with prices in the market's language ([SETUP.md](SETUP.md#medusa-dal-and-the-wiring-page-t12)). Chromium against `next start`: `/` is Greek with `12,00 €` (`el-CY`), `/us` English with `$14.00`, `/ch/fr` French with `12.00 CHF`. It also works for a market Medusa did not have when the code was written: with a Brazil region and `BRL` added to the backend's `config/markets.ts`, a map with `br` saved while the server ran served `/br` as `pt-BR` with `R$ 366,00` after 56 s, and the currencies row followed, with no storefront edit (D17). `pnpm typecheck`, `lint`, `test` (18 + **367** + 85) and `build` pass in CI's state (no `.env`, no database; the second `pnpm build` is a turbo hit), the Playwright `markets` suite passes (28), and 36 mutations were each caught (the first run caught 32; four tests were added for the rest). The plan changed in five ways, all written into it ([SETUP.md](SETUP.md#medusa-dal-and-the-wiring-page-t12), "What should change in the plan" under T12):
1. **`cached(fn, { name, tags, life })`.** Next refuses the plan's closure form (`Functions cannot be passed directly to Client Components`); one `"use cache"` function takes plain data, and `name` is part of the key and must be unique.
2. **A stopped backend gives the error state with HTTP 200, not 5xx.** The wiring page reads Medusa and Payload in a `<Suspense>` part behind `connection()` (so `next build` needs neither, and `/[market]` is `◐`); Next fixes the status when the shell is sent. The blocking alternative was measured and is worse (`ƒ`, still 200, Next's generic error page). The error state, the server staying up and the recovery when the backend returns all work.
3. **`@medusajs/types` is not a storefront dependency.** Adding it made pnpm resolve a second copy (the `vite` peer differs: 8.3.3 here, 7.3.7 in the backend) and `medusa build` failed with `TS2769`/`TS2322`/`TS2345` in files nobody had touched. Dropped; the DAL infers its types from the SDK.
4. **`medusaEnv()` is async** and imports zod when it runs, so the proxy bundle stays at 250 KB (a static import made it 353 KB).
5. **Regions are one cached list**, and `getSearchPriceCurrencies()` (D17) is its currencies.
