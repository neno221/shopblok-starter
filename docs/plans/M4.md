## 0. Before M4 starts: what I need from you

1. **Approve the scope.** Sixteen cloud tasks (T57 to T72, §5) and the Windows check W6, in the order of §4. Say "go" in the thread, or name what to drop or move; T57 and T58 start once you do. Nothing else in this list blocks them.
2. **D79, the blocks.** SPEC §7.4 lists 20 blocks with 60 variants between them. The default builds **each block once**, with one variant, as D57 did for the templates, so the editor has every block to build the homepage with, and M5 ("all blocks × variants") adds the other 40. The alternative is a core set of 12 in M4 and the other 8 in M5: a shorter M4, fewer blocks for the editor.
3. **D77, `ui-strings`.** SPEC §7.3 calls it a global. The code catalog has 718 messages; one global would be one admin form with 718 fields and a table of 718 columns per language, and every new message a migration. The default is a collection with **one document per message** (searchable, filterable by namespace, exported and imported as CSV for translators). The alternative is SPEC's global, with a tab per namespace.
4. **D76, the time zone.** SPEC says M4's sync moves each country's `timeZone` into the read-only part of `markets`. Medusa 2.21.2 has no time-zone field on a region, a country or the store (checked in its models), so the sync would have nothing to copy. The default keeps it **editable in Payload**, as M3 built it. The alternative stores it in each Medusa region's metadata and syncs it read-only.
5. **D71, Node 22.23.4.** Payload 3.92.1 (2026-10-27) needs Node `^22.23.4` and is the first 3.x release whose HTTP client (undici 7.30.1) has no advisory; 3.90.2's undici 7.29.0 has 18 in OSV, the "wait for a Payload release" of SETUP.md's T55 table. Node 22.23.4 is itself a security release (2026-10-20). T57 moves `.nvmrc` from 22.23.3. CI follows `.nvmrc` by itself. The cloud image has 22.22.0 and the environment's setup script upgrades only below 22.22, so until you paste T57's updated script into the environment's settings (optional, CLOUD.md will say how), each cloud session installs 22.23.4 at its start, about ten seconds. **Your PC needs Node 22.23.4 before W6**; I will not touch the PC without asking you.
6. **G8, Renovate (optional, about five minutes, §4a).** Renovate has opened nothing since 2026-10-15, although Next 16.4.3, Medusa 2.22.1 and Payload 3.92.1 came out since; it probably stopped when the repository moved to `neno221`. Either install the Renovate app for this repository again, or say you would rather drop it (T57 then removes `renovate.json`). Its three open PRs are handled in T57 either way.
